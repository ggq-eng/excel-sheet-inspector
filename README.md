# excel-sheet-inspector

> **分类**：原创 / AI 打磨 ｜ **文件数**：6 ｜ **仓库目录**：`excel-sheet-inspector`

## 📌 简介

**Excel 只读勘查工具**，两个脚本：

| 脚本 | 干什么 |
|---|---|
| `inspect_sheets.py` | 摸清结构：工作表清单、行列规模、原始网格、逐列统计 |
| `extract_bom.py` | 提取业务数据：BOM 报表的物料行、状态分布、零价行、同名相邻主/替对、两版差异 |

设计底线是**全程只读**——拿到一份来源不明、不能改动的 Excel，
先看清楚再动手；所有脚本头部都写明「不修改原文件」并遵守。

## 🎯 适用场景

- 拿到一份**来源不明、不能改动**的 Excel，需要先摸清结构
- 核对**两版 BOM 报表**的物料变动（新增/删除/数量变化/价格变化）
- 找出报表里的**零价行**（价格没填的物料）和**同名相邻的主/替代料对**
- 写自动化脚本前先确认表头长什么样，避免臆测列序

## ✨ 功能特性

- **`sniff()` 自动嗅探**：自动判断表头在第几行、分隔符是什么，不要求手工指参数
- **原始网格先打印**：遇到合并单元格、多级表头，先把原始网格打出来再看解析结果，不臆测
- **表头归一化**：`norm_hdr()` 把「物料编码 / 物料编码(个) / 物料编码 」归一成同一个键，
  不会因为全角空格或括号差异而漏配
- **数值容错**：`fnum()` 处理「1,200」「¥1200」「1200.00元」这类脏数值
- **两版差异分类输出**：新增 / 删除 / 数量变化 / 价格变化，四类分开列
- **全程只读**：只用 `pd.read_excel`（`read_only` 语义），无任何写回

## 🧭 各脚本详解

### `inspect_sheets.py` — 结构勘查

| 函数 | 作用 |
|---|---|
| `cell_str(v)` | 把单元格值统一转成可显示字符串（日期、公式、None 都不炸） |
| `sniff(path)` | 嗅探：工作表清单、每个表的行列规模 |
| `dump_sheet(df, name)` | 打印原始网格（前 N 行 N 列）+ 逐列非空数 / 唯一值数 / 类型分布 |

输出顺序刻意设计成：**先给工作表清单 → 再给每个表的规模 → 再给原始网格 → 最后给统计**，
这样即使表头不在第 1 行，也能从原始网格里直接看出来。

### `extract_bom.py` — BOM 提取与差异

| 函数 | 作用 |
|---|---|
| `norm_hdr(s)` | 表头归一化：去空格、去括号注记、统一全半角 |
| `load(path)` | 读入并定位表头行，返回 DataFrame |
| `fnum(v)` | 数值容错转换（千分位、货币符号、单位后缀） |
| `analyze(tag, path)` | 对单版本做全量分析：物料行、状态分布、零价行、主/替对 |

两版对比时，按物料编码（或归一化后的物料名）做主键，输出：

- **新增**：B 版有、A 版没有
- **删除**：A 版有、B 版没有
- **数量变化**：编码相同、数量不同（列出两个值）
- **价格变化**：编码相同、单价不同（列出两个值与差额）

## 🔬 工作原理

```text
.xlsx ──pd.read_excel──▶ DataFrame ──┬──▶ inspect_sheets（规模/网格/统计）
                                     └──▶ extract_bom（表头归一 → 行提取 → 差异分类）
```

- **不猜测表头**：先打印原始网格让人确认，再按归一化后的表头名取列
  （脚本按**列名**而不是列号取数据，所以源文件加列、挪列都不会错位）
- **差异以业务主键对齐**：用物料编码/物料名做 key，而不是行号 —— 行号会因插入而整体位移

## ❓ 常见问题

**Q：xls（老格式）能读吗？**
`pandas` 读 `.xls` 需要 `xlrd`，按需 `pip install xlrd` 即可。

**Q：合并单元格会被怎么处理？**
`pd.read_excel` 默认只保留左上角的值，其余为 NaN。所以 `dump_sheet` 会先把
原始网格打出来，让人确认合并区域再决定怎么解析。

**Q：为什么不用 `openpyxl` 直接读单元格，而绕一层 pandas？**
pandas 的列名机制天然适合「按表头名取列」，比 `ws.cell(row, col)` 更抗列序变化。
需要单元格级精度时再换 `openpyxl`。

**Q：两版差异里同名但编码不同的物料算同一个吗？**
不算。主键是编码；编码不同的同名物料会被当成「删除 + 新增」分别列出，
这是有意为之——同名不同编码通常是不同的物料批次或规格。

## ⚠️ 注意事项

- **只读**，不要试图用它改表
- 报表若有密码保护，需先手动解开
- 超大文件（10 万行以上）建议先用 `inspect_sheets.py` 看规模，再决定要不要全量跑
